This is the original play-test audit. Its line numbers, provider observations and proposed work refer to that run. See [current rc.6 runtime findings](v2-verification.md#2122-november-runtime-audits-against-rc6).

Four agents worked on it: identity, bloat, loop replay and a static audit. Each one's findings were then cross-checked by another agent.
- Verdicts: **C** = confirmed by a second agent; **R** = reproduced against the current code.
- Most of this run predates today's fixes. Items marked *(old data)* only change after a new run or a `/director redraft`.

## 5. Scope
The roleplay is a test bed. Fixes target the Director and Narrator card. The examples illustrate player identity, conflicting authored lore, and criteria tied to an offer.

The generic lessons behind them:
- I1: the player character's abilities from lore never reach the profile.
- R2: a thinking model in the tracker slot must not burn its limit; the code should split the batch.

## 6. Plan

**Phase 1: identity and settled.** These change what the narrator is told.
- I1: profile the player character from the persona plus their lore entry, keep stats from a forced re-profile, and add `/director profile pc`.
- I2: make story and lore profiles swipe-bound; a `present` name must be in the reply or the previous present list.
- I4: an alias list filled from lore keys and an `alias` cast change, used in `resolve` and shown in prompts.
- I5: status matching by similarity or a shared body-part word.
- L1: close criteria in code from settled ids.
- L2: `meta.settledSince`.
- L4: hashed ids.
- L5: count only the player's own settled items; use `quoteMatches`.
- L6: apply hidden spine deltas.
- L7: one completion helper.
- I3 needs an owner call (role characters).

**Phase 2: reliability.**
- R1: map 502/503/504, "Failed to fetch" and "NetworkError" to dropped; on a 4xx while streaming, retry once without streaming.
- L3: a per-module `transientUntil` (fix the test).
- R2: close a tracker batch by size (about 20k characters) and split it when the model thinks away its limit.
- L8: a 3-turn gap.
- L9: short quote plus speaker tag.
- L10, L11 (sort by weight), L12, R3 and the plancheck clip.

Done 22 Nov 2026, except L12 (skipped milestones): it changes how milestones conclude, so it is held for an owner call.

**Phase 3: length and bloat.** This needs an owner call, because it touches the "enriched" rule.
- A code-made length line after the history.
- Narrow the multi-character exception.
- "A long player message does not need a longer reply".
- Drop length words from the register.
- An opening-variation line.
- Planner cast limited to present characters and main cast.
- Observer player message clipped to 1.5k characters.
- `rejected` stored as counts.
- Replay token cache (R4).
